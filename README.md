# Aiplug CLI

AI 设计插件管理工具，用于 AI 设计插件的搜索、查看和安装。

## 安装

```bash
npm install -g @aidesignhub/aiplug
# 或不安装，直接用
npx @aidesignhub/aiplug --help
```

## 使用

```bash
aiplug search <关键词>     # 搜索插件
aiplug show <插件>         # 查看详情
aiplug install <插件>      # 给出安装命令
aiplug login               # 邮箱登录
aiplug --help              # 查看帮助
```
