# Aiplug CLI

Aiplug CLI - AI 设计插件管理工具，用于 AI 设计插件的搜索、查看与安装。

## 安装

```bash
npm i -g @aidesignhub/aiplug
```

需要 Node ≥ 22.6。也可以不装，用 `npx @aidesignhub/aiplug <命令>` 直接运行。

## 使用

```bash
aiplug search <任务或关键词>   # 搜索 AI 设计插件
aiplug show <地址>             # 查看插件详情
aiplug install <地址>          # 给出经核验的安装命令
aiplug login                   # 邮箱验证码登录
aiplug help [<命令>]           # 查看命令帮助
```
